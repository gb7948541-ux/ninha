UNIVERSO DE AMOR — ANA LUIZA

Como colocar as 5 fotos:
1. Abra a pasta "fotos".
2. Coloque suas cinco fotos dentro dela.
3. Renomeie exatamente assim:
   foto1.jpg
   foto2.jpg
   foto3.jpg
   foto4.jpg
   foto5.jpg
4. Abra o index.html.

IMPORTANTE:
- As fotos devem estar dentro da pasta fotos, ao lado do index.html.
- Se suas imagens forem PNG, você pode renomear para .png e alterar o final .jpg no app.js, mas o mais simples é usar JPG.
- Não precisa enviar as fotos aqui.

O projeto foi mantido com a mesma linguagem visual: entrada cinematográfica, queda pelas estrelas, galáxia, capítulos, transições e encerramento com partículas. O texto foi adaptado para um começo recente, sem declarações de amor, pedido de namoro ou linguagem de relacionamento.
